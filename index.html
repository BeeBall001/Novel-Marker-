設定

你的寫作，應該由你掌握。

Google Drive 跨裝置同步

輸入 Google OAuth 2.0 Web Client ID 後，即可授權 Quillframe 將專案備份到自己的 Google Drive。資料只存取由此應用程式建立或開啟的檔案。需要在 Google Cloud Console 啟用 Drive API、設定 OAuth 同意畫面，並將此網站來源加入授權 JavaScript 來源。

目前使用此瀏覽器本機儲存。填入 Client ID 後按「連結 Google」啟用雲端同步。

本機儲存

編輯內容會自動儲存在目前瀏覽器。請在不同裝置間同步前先連結 Google Drive，或使用「專案備份」手動移轉。
